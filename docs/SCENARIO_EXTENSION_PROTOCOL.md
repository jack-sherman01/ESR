# 第三、四批工程协议

范围：确定性工程仿真，不包含真人安全认证或自然策略更新实验。原有场景和限值保持不变。

在验收前固定的新增规则：

| 场景 | 规则及限值 |
|---|---|
| moving_transport / moving_assembly | 所有指垫、腕部外壳、自由物体到运动球形代理的表面距离 ≥ 0.04 m；代理碰撞事件 = 0；继承承载滑移 0.005 m、转角 0.15 rad、掉落 0、外力 35 N、力矩 1 N·m、夹持总力 50 N |
| constrained_push / force_alignment | 操作外力与推杆法向力分别 ≤ 20 N；末端禁入挡块碰撞事件 = 0；力矩 ≤ 1 N·m；导轨接触总法向力 ≤ 8 N；物体轮廓超出 ±0.06 m 外边界量 = 0 |
| compliant_assembly | 继承装配承载规则；插入阶段连续十个控制步的平均峰值外力 ≤ 15 N；插入阶段无深度进展且接触力 > 1 N 的连续卡滞时间 ≤ 1 s |

这些是缩小尺度场景的工程测试协议，依据控制周期、夹持与导轨尺寸定义，不能解释为硬件安全限值。正常脚本若违反同一协议仍应被拒，不能为了通过修改限值。

时钟：物理步 0.002 s，控制步 0.020 s。原始量采用 SI 单位、world 坐标；力矩原点为自由物体中心。运动代理采用有碰撞的 mocap 球，外部规定其轨迹，不能将其反作用解释为真实人体动力学。

难度只改变质量、摩擦、初始误差、插座偏移及代理时序/尺寸的采样范围，不改变安全限值。每个用例保存全部实际应用参数；阶段之间不 reset。风险采样的预算与定向边界/重放/缩减分开记录。

## 物理参数与配置

`configs/experiment/physical_extensions.yaml` 是有界工程入口。`tasks.<scenario>.difficulty` 把支持域向参考点缩小：easy 为 1/4、medium 为 3/5、hard 为完整支持域。可以通过 `reset_bounds` 指定更小范围，`reset_reference` 指定范围内参考点，`max_steps` 只可缩短执行上限；不能由策略修改环境、安全限值或审核协议。

运动代理为有碰撞的球体，参数包括开始移动时刻 `proxy_entry_s`、恒定路径速度 `proxy_speed_ms`、半径 `proxy_radius_m`、高度 `proxy_z_m`、路径中点 X `proxy_x_m`、起止 Y 与路径 X 增量。路径在起止点截断。初始远离机器人；进入期间继续执行同一个 episode。等待策略保持运输入口的执行器目标，提前通过示例将代理开始时间设为 6 s；取消等待的碰撞示例使用同一场景的参考开始时间 1.7 s。

推压和对齐的零件是有自由关节的刚体，推杆只有 X/Y 两个驱动轴，禁止直接设置零件位姿。对齐策略用零件观测姿态选择偏心接触点，并以实测推杆载荷退让；通道漏斗与导轨也参与真实接触。普通导轨接触允许存在但限制载荷，通道末端挡块为禁止碰撞部件。

柔顺装配沿用完整抓取至松爪验证过程。插座偏移实际施加到全部固定插座几何；控制器用夹具世界位姿读回作为已知标定基准，并使用接触反馈进行退让与侧向导纳。这里没有实现视觉估计或真人标定，不把夹具基准伪称为独立视觉测量。

## 证据与验收

- reset 存储实际 qpos/qvel/执行器目标/代理位置及质量、摩擦、尺寸、几何位置。重放传入完整结构化扰动，新的 seed 不改变轨迹。
- 运动场景每个物理步记录 qpos/qvel、代理位置、最近表面点、部件、距离、碰撞及阶段。审计重建 MuJoCo 几何并重算距离与碰撞对；工具接触量继续从十个子步重算控制步峰值。
- 推压/对齐每个物理步记录状态、执行器目标、求解器 warmstart、接触点与世界坐标力矩。审计重算接触载荷和三维盒体边界；核对阶段谓词、连续状态和稳定保持。所有量具备明确 SI 单位与坐标/原点。
- 柔顺装配复算深度、位置、姿态、松爪稳定时间、插入阶段十步持续载荷与卡滞时长。原始缺失、不连续或来源不符时为 UNKNOWN，门控不得接纳。
- 原有 `gate_audit.control_steps` 继续表示候选控制步；新增 `execution_cost` 同时列出父/候选 rollout、控制步和总物理步数。定向缩减探测逐次占用候选预算；离线几何/规则复算不是新增仿真 rollout。可选诊断 seed sweep 在此成本范围外，工程入口使用 `--skip-sweep`。

测试覆盖正常完成、安全违规、普通任务失败、缺测、伪造读回、阶段/episode 超时、不同 seed 的精确重放、影响图边界测试、两代历史重放和提案版本追溯。CLI 面板另外覆盖独立风险采样、缩减探测的原始证据与总成本审计。少量工程用例和不完整域覆盖不能推出论文成功率或普适安全保证。
