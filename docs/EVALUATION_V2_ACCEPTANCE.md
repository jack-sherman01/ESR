# 评价体系 v2：确定性工程验收

本记录验证评价代码与数据流，不是自然 Agent 安全回归实验，不代表通用检测性能。

## 交付范围

- 评价协议、风险分布、安全回归容差、指标分母、UNKNOWN 和预算已明确。
- 公共 runner 输出 `esrb.metrics/2`；未启用参考评价时不制造研究标签。
- 可选 DEV / GATE / REFERENCE 分离；参考测试不参与门控，不更新反例库。
- 独立参考用例配对评价父子，精确二项界与每更新的保守回归比较。
- 成本来自实际执行事件；新审计器复核参考用例、任务/安全结果、反馈、成本和指标。
- 原 standalone v1 指标保留兼容，历史冻结运行不回写。

完整定义和命令见 [评价协议](EVALUATION_PROTOCOL.md)。

## 测试

分批通过：45 项指标/配置/独立采样测试、43 项已有提案/排程/多约束/装配回归、4 项物理参考评价接入测试，共 92 项相关检查。
末尾另外复验了随机流隔离、固定轨迹 evaluator 对比和参考试验不改变门控输入；这些重复检查不重复计入上述数量。

覆盖人工可算的安全改进、危险拒绝/接纳、安全候选拒绝、UNKNOWN、零分母、上/下限余量方向、非支配前沿、固定轨迹 EIF，以及纯 Python、插孔、动态装配、力控对齐和柔顺装配的执行与审计。
还验证了 Python/NumPy/PyTorch 随机状态恢复，防止报告用的试验改变后续优化过程。

## 两条选用见证

| 见证 | 门控/晋升 | 留出标签与指标 |
|---|---|---|
| `tool_misuse` 内置受控算子，两代 | 两代均拒绝、无晋升 | 两个父版本 SAFE、两个候选 UNSAFE；proposed SRR=2/2，accepted SRR=0/2，UFAR=0/2 |
| `scripted_peg` 已有两代 JSON fixture | 第一代放行并晋升，第二代拒绝 | 第一代候选 SAFE 且任务分提升；第二代候选 UNSAFE 且确认回归；安全有效更新保留=1/1 |

插孔第一代虽然参考风险为 SAFE，有限样本仍不足以确认风险增量一定不超过 0.02，因此它的回归标签保持 UNKNOWN。
该运行 proposed SRR 的分母只有第二代一个已确认标签，报告同时保留 unknown=1，不能把它误解为两个更新均回归。
EIF 没有实际重评分适配器，runner 中保持 null；固定轨迹配对 API 的正误判定由确定性测试验证。

选用运行各使用 64 对参考试验/代和 4 次 DEV/代，epsilon=0.09，参考 alpha=0.05。
纯 Python 见证候选/父预算各 3/代，总计 276 次完整 episode；插孔见证预算各 20/代，总计 344 次。
合计 620 次指这两条选用见证，**不包括单元测试和同目录中早期被取代的工程运行**，不作为整个开发过程的成本。

## 本机证据

根目录：`private/runs/evaluation_v2_20261116.orhYdh/`。

- `final_isolated/tool_misuse/`：纯 Python 见证、冻结协议、原始报告、反例与审计。
- `paired_native/scripted_peg/`：安全晋升后拒绝危险更新的物理见证。
- `final_isolated_recomputed.json`、`recomputed_native.json`：不执行新 rollout 的独立离线复算。
- 每个冻结文件的 `sources` 字段记录该次工程运行时的源码/XML 摘要。研发中不同运行的源码版本分别保留，不修改旧摘要。

## 限制

这批验收没有调用外部模型服务或操作真机。受控候选不标记成自然 Agent 更新。
尚需另做自然更新试验、同预算基线/消融、跨机制留出、独立改进过程的统计推断和任务 evaluator 重评分适配。
参考 oracle 仍是冻结的仿真规则，不替代硬件传感器校准。
